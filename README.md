# MEA
# MEA電解タイマー（GitHub Pages 版）

Claude を使わずに、URL だけで誰でも使えるタイマー。
記録は **その端末のブラウザ** に必ず保存され、設定すれば **Google スプレッドシート** にも保存される。

```
pages/
├─ index.html          ← GitHub Pages に置くページ（これ1つで動く）
├─ apps_script/Code.gs ← スプレッドシート側に貼るスクリプト
└─ README.md           ← この説明
```

---

## A. スプレッドシート側の準備（管理者が1回だけ）

1. Google ドライブで **新しいスプレッドシート** を作る（名前は例えば「MEA操作記録」）。
2. メニュー **拡張機能 → Apps Script** を開く。
3. 最初からある `コード.gs` の中身を全部消し、`apps_script/Code.gs` の中身を貼り付けて保存。
4. **合言葉を設定する**: 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ: `TOKEN`
   - 値: 推測されにくい文字列（例: `mea-` + ランダムな英数字20文字くらい）
5. 右上 **デプロイ → 新しいデプロイ** →「種類の選択」の歯車 → **ウェブアプリ**
   - 説明: なんでもよい
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ Google アカウントへのアクセスを **許可**（「安全ではないページ」と出たら「詳細」→「（プロジェクト名）に移動」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える。

> 「アクセスできるユーザー: 全員」は、URL と合言葉を知っている人だけが書き込める、という意味になる（合言葉が違うリクエストは拒否する）。
> ブラウザで URL を直接開いて `{"ok":true,"app":"MEA timer"}` と出れば公開できている。

`Code.gs` を後から書き換えたら、**デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ**（URL は変わらない）。

## B. GitHub Pages に公開（管理者が1回だけ）

コマンド不要の方法:
1. https://github.com にサインイン → 右上「+」→ **New repository**
   - Repository name: 例 `mea-timer`
   - **Public**（無料プランで Pages を使うには公開リポジトリが必要。ページの中身が見えるだけで、記録や合言葉は含まれない）
   - 「Create repository」
2. 作ったリポジトリで **Add file → Upload files** → `index.html` をドラッグ → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch**、Branch: **main** / **(root)** → Save
4. 1〜2分後、`https://<ユーザー名>.github.io/mea-timer/` で開けるようになる

更新するときは、同じく **Add file → Upload files** で `index.html` を上書きアップロード。

（git を使う場合）
```
cd E:\CO2RR\scripts\MEA\pages
git init -b main
git add index.html README.md apps_script/Code.gs
git commit -m "MEA timer"
git remote add origin https://github.com/<ユーザー名>/mea-timer.git
git push -u origin main
```
※ リポジトリに置くのはこのフォルダだけ。測定データや他のスクリプトは入れない。

## C. タイマーをつなぐ（各自・各端末で1回）

1. 公開した URL をスマホで開く →「設定」タブ
2. ウェブアプリ URL・合言葉・実験者名を入れて **「保存して接続テスト」**
3. 「接続できました」と出ればOK。右上が「スプレッドシート保存済み HH:MM:SS」になる

### メンバーに配るとき
自分の端末で設定が済んだら、「設定」タブの **「設定リンクをコピー」** → そのリンクを研究室の Slack/LINE などで送る。
受け取った人はリンクを開いて、実験者名を入れて「保存して接続テスト」を押すだけ。

> 設定リンクには合言葉が入っている。研究室外には渡さないこと。
> 合言葉を変えたいときは、スクリプト プロパティの `TOKEN` を変える（デプロイし直しは不要）→ 全員に新しい設定リンクを配る。

## 使い方（測定のたび）

1. サンプル名・目的電流を入れて、ポテスタのプログラム開始と同時に **スタート**
2. 目的電流に達したら **定電流到達を記録**
3. 音と赤点滅で知らせる操作を **実施を記録**（ガス流量・秤量は値を入れてから）
4. 終わったら PC で同じ URL を開き **記録一覧 → CSVを保存** → 測定CSVと同じフォルダへ
   → `解析.bat` / `read_potential_MEA.bat` が本測定窓を自動で使う

スプレッドシートには 1測定 = 1行（サンプル名・実験者・開始・本測定窓・状態・記録数）で溜まるので、
一覧を見るだけならスプレッドシートを開けばよい。

## 保存の仕組みと注意

| | この端末 | スプレッドシート |
|---|---|---|
| いつ保存 | 操作のたび（常に） | 操作のたび（設定時。電波がないと後で再送） |
| 誰が見られる | その端末だけ | 合言葉を知っている全員の「記録一覧」とシートの共有相手 |
| 消すと | 「記録一覧 → 削除」で両方から消える | 行を直接消してもよい |

- 合言葉を知っている人は **全員の記録を見られ、消せる**。研究室内での共用を前提にした作り。
- 画面はつけたままにする（ロックすると音が鳴らない）。
- 同じ記録を2台で同時に操作しない。
- 手順（操作名・タイミング・10分）を変えるときは `index.html` の `CONFIG` を編集してアップロードし直す。
